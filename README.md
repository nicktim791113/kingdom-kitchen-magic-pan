# 王國廚房：我的魔法平底鍋

2-3 歲幼兒向的互動料理小遊戲原型。這一版聚焦完整料理回合：接單、洗水果、切水果、下鍋、攪拌、獎勵。

目前水果：蘋果、香蕉、草莓、橘子。

## Play

https://nicktim791113.github.io/kingdom-kitchen-magic-pan/

## Run

Open `index.html` directly, or serve the folder with a static server:

```powershell
python -m http.server 5173
```

## Deploy

The `main` branch deploys to GitHub Pages automatically through GitHub Actions.

To commit and push local changes:

```powershell
npm run push -- -Message "Describe your update"
```
